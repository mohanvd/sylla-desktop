# Sylla for desktop

The installers for [Sylla](https://sylla.study), the study tracker, as a desktop app.

**Download for Windows:** [sylla.study/download/windows](https://sylla.study/download/windows)

The app keeps itself up to date: new versions download in the background and install the next time you close Sylla.

Windows may say it protected your PC the first time you run the installer, because the app is new. Choose **More info**, then **Run anyway**.

The app's source lives with Sylla itself; this repository only holds its releases.
